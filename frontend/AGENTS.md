## Frontend design consistency

Before making any frontend changes, read [DESIGN.md](../DESIGN.md) and follow its guidance for page layouts, modals, shared forms, labels, validation, motion, and action placement.

Before implementing any new UI, inspect the existing frontend design language and identify the closest reusable components and reference screens. New features must reuse existing typography, spacing, colors, radii, shadows, icons, forms, overlays, responsive patterns, and terminology. Do not introduce a new UI library or isolated visual system. If existing styles conflict, follow the most recent widely reused pattern and report the ambiguity before implementation.
